# 대규모 그래프 성능 기준

그래프 스냅샷 저장은 노드 100,000개, 엣지 250,000개, 진단 50,000개,
소스 해시 100,000개를 상한으로 둔다. 상한을 넘는 입력은 저장하지 않고 명확한
검증 오류를 반환해 메모리 사용량이 무제한으로 증가하지 않게 한다.

화면 렌더링은 뷰별로 최대 60개 노드와 300개 엣지만 표시한다. 표시 전에 엣지 ID를
deterministic하게 deduplicate하고, 표시되지 않은 항목 수를 모델에 기록한다.

기준 fixture는 `apps/desktop/tests/graphViewModel.test.mjs`의 상한 테스트를 사용한다.
향후 실제 프로젝트 측정에서는 snapshot 저장 시간, peak RSS, 첫 렌더 시간, 키보드
탐색 응답 시간을 같은 fixture 크기별로 기록한다.
